# Add Test Users - Direct URL

## Direct Link to OAuth Consent Screen

**Click this link to add test users:**

```
https://console.cloud.google.com/apis/credentials/consent?project=<YOUR_PROJECT_ID>
```

---

## Step-by-Step Instructions

### 1. Open the Link Above
This takes you directly to the OAuth consent screen for your project.

### 2. Scroll Down to "Test users" Section
You'll see a section titled **"Test users"** on the page.

### 3. Click "+ ADD USERS" Button
This opens a dialog to add email addresses.

### 4. Enter Your Email
- Enter the **exact email address** you use to sign in with Google
- Make sure it matches exactly (case-sensitive)
- Click **"ADD"**

### 5. Verify It's Added
- Your email should appear in the test users list below
- You can add multiple emails if needed

### 6. Wait 10-30 Seconds
Google needs a moment to sync the changes.

### 7. Try Signing In Again
Go back to http://localhost:5000/business-signup.html and try again.

## Alternative Navigation Path

If the direct link doesn't work, navigate manually:

1. Go to: https://console.cloud.google.com
2. Select project: **<YOUR_PROJECT_ID>**
3. Click: **APIs & Services** (left sidebar)
4. Click: **OAuth consent screen**
5. Scroll to: **Test users** section
6. Click: **+ ADD USERS**
