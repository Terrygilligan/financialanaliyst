📚 Admin Documentation & Guides

🎯 Admin Responsibilities

As an admin, you have access to system-wide data and management features.

📊 Dashboard Features

  • System Statistics: View total receipts, success rates, active users, and amounts processed
  • Analytics Charts: Visual breakdown of receipts by category and status
  • All Receipts Viewer: Search and filter all receipts from all users
  • Error Logs: Monitor processing errors and troubleshoot issues
  • User Management: View all users and their activity

🔍 Key Admin Tasks

  1. Monitor Errors: Check the "Errors & Unprocessed" tab regularly
  2. Review Flagged Receipts: Visit Admin Review for validation warnings
  3. User Support: Check user activity and troubleshoot issues
  4. Data Quality: Review analytics for data accuracy

📝 Admin Review Workflow

  • Navigate to Admin Review page
  • Review flagged receipts and validation warnings
  • Approve or reject receipts after verification
  • Add notes for audit trail purposes

🔐 Admin Access Setup

Two methods available for granting admin access:

Method 1: Firestore Collection (Easiest)

  1. Go to Firebase Console → Firestore
  2. Create collection: admins
  3. Add document with admin email as ID
  4. Add field: email (string) with the admin email value
  5. User must sign out and sign back in

Method 2: Custom Claims (More Secure)

  1. Deploy Cloud Functions: firebase deploy --only functions
  2. Get user UID from Firebase Console → Authentication
  3. Call function: firebase functions:call setAdminClaim --data '{"uid":"USER_UID"}'
  4. User must sign out and sign back in

👥 Admin Roles Explained

  • System Admin: Full access to all features, user management, system configuration
  • Permissions: View all data, approve/reject receipts, manage users, access error logs
  • Setup: Add admin email to Firestore admins collection

🏢 Data Isolation & Silos

Enterprise Features

  • 🏗️ Field Builder: Define custom fields (e.g., Odometer, Project ID) for Gemini to extract.
  • 👥 Delegated Management: Create Driver accounts scoped to your business.
  • 🛡️ Absolute Isolation: No business can see another's data or users.

Security Enforcement

  • ✅ Identity Based: Users must have a businessId claim in their auth token.
  • ✅ Path Scoped: Firestore rules prevent users from querying data outside their silo.
  • ✅ Storage Isolation: Images are stored at /tenants/{businessId}/drivers/{uid}/....
